# tilttoken

Tilt host/token network string helpers for config audits.

**Site:** https://theworker02.github.io/tilttoken/

## Install / run

```bash
git clone https://github.com/theworker02/tilttoken.git
cd tilttoken
node src/cli.js
node --test
```
